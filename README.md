## Projects

Currently I have 2 projects to my name.

The first one is an [Inventory Management API](https://github.com/Illia-Khaytul/Inventory-Manager-API).
It allows for customers to create and manage their orders and for operators to create and manage available products.
Customer orders are filled automatically as asynchronous tasks to reduce the response time.
The API also uses a JWT based authentication system with database persisted sessions and rotating, single use, opaque refresh tokens.

*Note: This project is still unfinished and is currently in active development.*

The other project is a [Book Catalogue API](https://github.com/Illia-Khaytul/Book-Catalogue-API).
This is a learning project and the first one I have ever uploaded on GitHub.
It allows users to create a new account and manage (basic CRUD operations) the books through the API.
It uses a basic user credential authentication and has no book ownership or relevant security measures.
Anyone can register and begin doing what they pleased.

As it was said earlier, this is a learning project and is therefore not suited for production.
Its main purpose is to help me get accustomed to using versioning tools (git) and following the correct development flow.
